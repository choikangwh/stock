# 📊 실시간 주식 분석 대시보드 & CLI 리포트 생성기

Gemini 2.5 Flash 모델과 야후 파이낸스(yfinance) 실시간 재무 데이터를 결합한 스마트 주식 분석 도구 패키지입니다. 
웹 기반의 아름다운 대시보드 화면(Streamlit)과 터미널에서 즉시 실행 가능한 CLI 분석 보고서 생성기를 모두 지원합니다.

---

## 🌟 주요 기능
1. **실시간 정보 수집**: `yfinance`를 활용해 기업의 실시간 주가, 주가 변동 방향, 최근 5개년 재무제표(손익계산서, 대차대조표, 현금흐름표)를 즉시 수집합니다.
2. **뉴스 실시간 검색 & 요약 (Google Search Grounding)**: Gemini 2.5 Flash 모델의 구글 검색 기능을 활성화하여 해당 주식 관련 최신 뉴스와 주가 변동 원인을 실시간으로 분석합니다.
3. **종합 분석 리포트 자동 생성**: 재무성과, 가치 평가(Valuation), 비즈니스 모델 및 경제적 해자(Moat), 성장 전략, 리스크 분석, 매크로 시장 동향을 아우르는 글로벌 투자은행급 국문 보고서를 작성합니다.
4. **AI 데이터 챗 비서**: 대시보드 내에서 생성된 분석 보고서 내용을 기반으로 주식에 대한 모든 의문점을 묻고 답할 수 있는 전용 챗봇을 제공합니다.

---

## 📋 사전 요구사항
* **Python 3.9 이상**이 설치되어 있어야 합니다.
* **Google Gemini API Key**가 필요합니다.
  * API Key가 없는 경우 [Google AI Studio](https://aistudio.google.com/)에서 무료로 발급받으실 수 있습니다.

## 🚀 실행 방법 (가장 간단한 원클릭 방법)

배포 폴더(압축 파일 또는 Git 저장소)를 다운로드한 후 아래 실행 스크립트를 더블클릭하거나 실행하기만 하면 가상환경 생성, 패키지 설치, 대시보드 구동까지 자동으로 진행됩니다.

### 윈도우 (Windows)
* **방법 A (단독 실행 파일 - 가장 권장)**: 
  1. `dist/StockDashboard.exe` 파일을 더블클릭하여 즉시 대시보드를 실행합니다.
  2. 별도의 Python 설치나 세팅 없이 즉시 가동됩니다.
* **방법 B (자동 배치 스크립트)**:
  1. 폴더 내부의 `run.bat` 파일을 더블클릭하여 실행합니다.
  2. 자동으로 필요한 패키지가 가상환경에 설치된 후 웹 브라우저 창이 열리며 대시보드가 실행됩니다.

### 맥 / 리눅스 (macOS / Linux)
1. 터미널을 열고 프로젝트 폴더 경로로 이동합니다.
2. 실행 권한을 부여한 뒤 스크립트를 실행합니다:
   ```bash
   chmod +x run.sh
   ./run.sh
   ```

## 🛠️ Python 패키지로 설치 및 배포하기

이 프로젝트는 표준 `pyproject.toml`을 지원하므로 다른 사람에게 파이썬 패키지(`pip`) 형태로 손쉽게 배포하고 전역 명령어로 실행할 수 있게 만들 수 있습니다.

### 1. 패키지 빌드 (배포자용)
프로젝트 루트 폴더에서 아래 명령을 실행하여 배포용 패키지 파일(Wheel 및 Source Archive)을 생성합니다.
```bash
pip install build
python -m build
```
빌드가 완료되면 `dist/` 폴더에 `.whl` 파일과 `.tar.gz` 파일이 생성됩니다. 이 파일을 다른 사람에게 전달하시면 됩니다.

### 2. 패키지 설치 (사용자용)
전달받은 파일 경로를 입력해 패키지를 설치합니다:
```bash
# 로컬 소스 디렉토리에서 바로 설치하는 경우
pip install .

# 빌드된 Wheel(.whl) 파일로 설치하는 경우
pip install dist/stock_analyst_dashboard-1.0.0-py3-none-any.whl
```

### 3. 설치 후 전역 명령어 실행
설치가 완료되면 터미널/명령 프롬프트 어디서나 아래 명령어를 입력해 대시보드와 CLI 생성기를 단독 실행할 수 있습니다.

* **웹 대시보드 실행**:
  ```bash
  stock-dashboard
  ```
* **터미널 인터랙티브 CLI 분석기 실행**:
  ```bash
  stock-analyzer
  ```

## 🔑 Gemini API Key 입력 방법
* **웹 대시보드**의 경우, 상단 종목 검색창 옆의 **"Gemini API Key 입력"** 칸에 사용자가 직접 본인의 API Key를 입력하여 실행할 수 있습니다. 
* 매번 입력하는 번거로움을 줄이려면 프로젝트 루트 폴더에 `.env` 파일을 만들고 아래와 같이 저장하여 기본값으로 자동 로드되도록 할 수도 있습니다:
  ```env
  GEMINI_API_KEY=본인의_API_키_입력
  ```

## 🌐 Streamlit Community Cloud에 무료로 배포하기
이 대시보드는 인터넷상에 공개 배포하여 누구나 브라우저로 접속해 본인의 API Key만 넣고 사용하게 만들 수 있습니다.

1. 이 소스 코드를 본인의 **GitHub 저장소(Public or Private)**에 올립니다.
2. [Streamlit Share](https://share.streamlit.io/)에 접속하여 가입 후 **"New app"**을 클릭합니다.
3. 해당 GitHub 저장소, 브랜치(`main`), 메인 파일 경로(`app.py`)를 지정하고 **"Deploy!"**를 누릅니다.
4. 배포가 완료되면 전 세계 어디서든 고유 웹 링크를 통해 대시보드 서비스를 이용할 수 있습니다.
